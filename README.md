## Concepts

| Concepto    | Qué significa                                     | Ejemplo
|-------------|---------------------------------------------------|--------
| Filosofía   | Los principios que guían tus decisiones           | Preferir soluciones simples y homogéneas
| Diseño      | Cómo organizas una solución concreta              | Dividir una funcionalidad entre tres funciones o resolverla en una
| Abstracción | Representar una idea ocultando detalles concretos | Crear una API común para distintos mecanismos de lectura

No son categorías independientes. Una decisión de diseño puede estar guiada por
la filosofía del programador. Y una abstracción puede estarlo también por una
decisión de diseño.
